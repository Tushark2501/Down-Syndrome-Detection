# Dataset

## Overview

This dataset is used for the **Down Syndrome Detection using ResNet50 Transfer Learning** project.

It contains facial images belonging to two classes:

- **Down Syndrome**
- **Healthy**

The dataset is organized into separate training, validation, and testing sets.
